An instrument's accuracy specification is a table in a PDF: one row per range, per calibration
interval, in parts per million of reading plus parts per million of range, with a temperature band
and a coefficient for every degree outside it. Nothing downstream can price a measurement until
that table is data. The model reads the manual and fills the schema, code validates the rows and
computes the budget from them, and a person checks every row against the manual before a number is
quoted from it. The failure this recipe exists for is not a garbled row. It is a clean, plausible
row taken from the wrong calibration interval or the wrong range, which produces an uncertainty
three times too small and looks exactly like a correct one.
