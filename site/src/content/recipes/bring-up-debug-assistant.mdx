A board's output is low and the next measurement to take depends on what the last one said. That is the shape an agent fits. It also means something on the bench is going to be set, and set points are where a bench goes from a debugging session to a damaged board, so the tools divide cleanly: queries run unattended and anything that sets state goes through a code-side envelope and a person.
