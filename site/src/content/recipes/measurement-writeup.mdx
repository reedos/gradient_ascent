The measurements are done, the arithmetic is done, and what is left is the part that takes the
afternoon: turning a lab notebook and a table of computed results into a report a reviewer can
read. Code computes every number and places it. The model writes the sentences around the numbers
and is never asked for one. A check in code then confirms that every figure in the draft is a
figure code produced, character for character, before a person reads it. That check costs nothing
and it is what makes one model call safe to make here.
