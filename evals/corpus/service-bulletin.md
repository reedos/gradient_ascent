# Service Bulletin SB-2026-07

Issued 2026-06-01 by Halvorsen Technical Services. Subject: revised maximum vent run for the
DR-520 dryer.

## 1. Summary

This bulletin revises the maximum vent run specification for the DR-520 dryer. It does not
affect the DR-210, and it does not affect either dishwasher model.

## 2. Revised Vent Specification

Field reports of reduced airflow on DR-520 installations led Halvorsen Technical Services to
retest vent runs at the original specification. Testing found that airflow at the drum drops
below the level needed for reliable drying before the previously published maximum is reached.
The maximum vent run for the DR-520, using 4-inch rigid metal duct, is now 25 feet, with up to 3
elbows counted against that length. This supersedes the 35-foot, 4-elbow figure published in the
DR-520 owner's manual (revision 2024-03-01) and in the Installation Guide (revision 2023-09-01).
The DR-210 vent specification is not affected by this bulletin and remains 35 feet with up to 4
elbows, as published in the DR-210 owner's manual.

## 3. Affected Units

This bulletin applies to all DR-520 units, electric and gas, regardless of serial number or
production date. It is not tied to a specific manufacturing window, unlike a recall: the change
is to the installation specification itself, not to a defect in a batch of units, so every
DR-520 in the field is affected the same way.

## 4. What to Do

For a new DR-520 installation, measure the planned vent run before installation and keep it
within the revised limit. For an existing DR-520 installation with a vent run longer than 25
feet, have the vent inspected by authorized service; a long run does not require immediate
replacement but can produce error code F5 (airflow restriction) as described in
`troubleshooting.md`. Shortening the run, reducing the elbow count, or adding an in-line booster
fan approved by Halvorsen Technical Services are the accepted ways to bring an existing
installation back within specification.

## 5. Authorization

Issued by Halvorsen Technical Services. This bulletin is the current authoritative source for
DR-520 vent length until a further revision is issued.
