# Halvorsen Troubleshooting and Error Codes

Applies to: DW-300, DW-480, DR-210, DR-520. Revision 2025-06-01.

## 1. How to Read This Table

Each error code below names the fault, the models it applies to, and the first step to check
before calling for service. If the code repeats after the listed step, contact an authorized
service center rather than continuing to run the unit.

## 2. Dishwasher Error Codes

- E1, Water Supply Fault (DW-300, DW-480): check that the hot water shutoff valve is open and
  the supply line is not kinked.
- E2, Drain Fault (DW-300, DW-480): check the drain hose for a kink and clean the filter.
- E3, Door Latch Fault (DW-300, DW-480): confirm the door is fully closed and latched.
- E4, Heating Element Fault (DW-300, DW-480): do not continue to run the unit; contact service.
- E5, Overflow or Leak Sensor Tripped (DW-480 only): the leak cutoff sensor has detected
  standing water. Shut off the water supply at the valve and contact service.

## 3. Dryer Error Codes

- F1, Motor Overload (DR-210, DR-520): allow the motor to cool for 30 minutes before restarting.
- F2, Thermal Fuse Open (DR-210, DR-520): this is a safety cutoff. Do not reset or bypass it;
  the unit requires authorized service before further use.
- F3, Moisture Sensor Fault (DR-210, DR-520): clean the sensor bars inside the drum with a soft
  cloth.
- F4, Heating Element Fault (DR-210, DR-520): do not continue to run the unit; contact service.
- F5, Airflow Restriction or Vent Blockage (DR-210, DR-520): check the lint filter and the vent
  run for lint buildup or an excessive vent length; a vent run longer than the current
  specification for the model can trigger this code even with a clean filter.

## 4. General Steps Before Calling Service

Before contacting service, unplug the unit for one minute and plug it back in to clear a
transient fault. Confirm the circuit breaker has not tripped. Confirm the door or lid is fully
closed. Write down the exact error code and the cycle that was running.

## 5. When to Call Authorized Service

Call authorized service immediately for E4, F2, or F4, and for any code that repeats after the
step listed in sections 2 and 3. Have the model number, serial number, and date of purchase
ready when you call.
